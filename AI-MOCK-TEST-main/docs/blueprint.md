# **App Name**: QuantumQuizzes AI

## Core Features:

- AI-Powered Question Generation: Utilize OpenAI API to dynamically generate a variety of unique and relevant bank exam questions, avoiding repetition for the same student across mock exams.
- AI-Driven Answer Evaluation: Employ AI to evaluate student answers, assign scores, and identify weak and strong topics based on performance. This tool detects topic weaknesses.
- Personalized Exam & Feedback Generation: Automatically generate new mock exams focused on the student's weakest topics identified by AI. Provide personalized AI-based feedback for improvement after each exam.
- Student Authentication & Profile Management: Secure student login and signup, allowing users to manage their profiles and track their overall progress.
- Performance Analytics Dashboard: Provide a comprehensive dashboard displaying exam history, topic-wise performance analysis, and progress graphs.
- Adaptive Difficulty: Automatically adjust the difficulty level of subsequent mock exams based on the student's historical performance, ensuring a tailored learning curve.
- Admin Panel: A backend interface for administrators to manage questions, users, and overall system settings, complementing the student experience.

## Style Guidelines:

- Primary color: A deep, authoritative violet (#59288A) to signify intelligence and modern professionalism.
- Background color: A subtle, dark violet (#1A0A29) to create a sophisticated and focused dark theme.
- Accent color: A vibrant medium blue-violet (#5252E0) for key interactive elements and to draw attention to critical insights on dashboards.
- Headline and body font: 'Inter', a grotesque sans-serif, for a modern, objective, and highly readable experience, ideal for displaying data and text-based questions clearly.
- Utilize modern, clean, and consistent line-style icons to enhance navigability and understanding of data representations and analytical sections.
- Implement a clean, spacious dashboard layout with a clear information hierarchy, optimized for presenting analytical data and progress graphs. The design will be fully responsive across devices.
- Incorporate subtle, smooth transition animations for page navigation and interactive elements. Chart.js graphs will feature elegant entry animations to make data presentation more engaging.
